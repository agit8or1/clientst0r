Permission Levels
Read-Only

Can view data but cannot make changes. Safest option for integrations that only need to read data.

Editor

Can create, update, and delete resources. Suitable for automation scripts that need to modify data.

Admin

Full access to data and can manage integrations. Use with caution.

Owner

Complete access including user management and organization settings. Only create if absolutely necessary.

Best Practices
  • Use separate keys for different integrations
  • Grant minimum required permissions
  • Rotate keys regularly
  • Delete unused keys immediately
  • Never commit keys to version control
  • Store keys in environment variables
