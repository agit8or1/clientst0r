{% load i18n static %}{% comment %} The settings workspace header, built from core.navigation (SETTINGS_CATEGORIES via primary_nav → pnav.workspace): the nine categories as tabs, the current category's pages as a second row, and a search over every settings page this user may open. base.html renders it (through core/_work_context.html, with settings_frame=True) on every page that belongs to a settings category, including sub-pages listed in a tab's `also`. Settings page templates used to include this file in a left-hand column with `active_page="…"`; an include without settings_frame now renders nothing, so an old include is harmless. Every link already passed its page's own check (the gates in navigation.py and the URL-prefix probe), so nothing here answers 403.
