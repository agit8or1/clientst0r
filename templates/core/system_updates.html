One-Time Setup Required for Web-Based Updates

To enable one-click updates from the web UI, you need to configure passwordless sudo. This is a one-time setup that allows the web interface to restart the Gunicorn service automatically.

Run this command once on your server:

sudo tee /etc/sudoers.d/clientst0r-auto-update > /dev/null <<'SUDOERS'
{% comment %} v3.17.520: was a single line granting /usr/bin/systemd-run and /usr/bin/tee bare — either of which is root in all but name, since systemd-run runs any command as root and tee writes any file it is pointed at. Narrowed to exactly what the updater issues; keep this in step with scripts/install_auto_update.sh. {% endcomment %}
administrator ALL=(ALL) NOPASSWD: /usr/bin/systemctl reload clientst0r-gunicorn.service
administrator ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart clientst0r-gunicorn.service
administrator ALL=(ALL) NOPASSWD: /usr/bin/systemctl status clientst0r-gunicorn.service
administrator ALL=(ALL) NOPASSWD: /usr/bin/systemctl daemon-reload
administrator ALL=(ALL) NOPASSWD: /usr/bin/systemd-run --on-active=3 --system /usr/bin/systemctl restart clientst0r-gunicorn.service
SUDOERS
sudo chmod 0440 /etc/sudoers.d/clientst0r-auto-update

After running this command: Refresh this page and you'll be able to click "Apply Update" to update with a single click!
Without this setup, you'll need to update manually via command line each time. These grants are deliberately narrow — each line is one command the updater actually runs, so this does not give the web app general root access. scripts/install_auto_update.sh installs the same set automatically.

Manual Update from CLI
Recommended: Use the Update Script

The easiest way to update is using our automated update script. It checks everything first, then runs the update safely:

cd /path/to/your/clientst0r
# (use find command below if you don't know the path)
./update.sh

The script will:

  • ✓ Check you're in the correct directory
  • ✓ Verify git repository and virtual environment
  • ✓ Warn about uncommitted changes
  • ✓ Pull updates from GitHub
  • ✓ Install dependencies
  • ✓ Run migrations
  • ✓ Collect static files
  • ✓ Restart the service
  • ✓ Show current version
Show Manual Step-by-Step Instructions

For advanced users who prefer manual updates via command line:

Important: Copy and run these commands ONE AT A TIME, not all at once. Wait for each command to complete before running the next one.
Step 1: Navigate to Application Directory

Find where your application is installed:

find /home -name "manage.py" -type f 2>/dev/null | grep clientst0r
# This will show the path to your installation

Then navigate to that directory (replace with YOUR path from above):

cd /path/to/your/clientst0r
# Example: cd /home/administrator/clientst0r
# OR: cd /home/administrator
Step 2: Verify Location
ls manage.py venv/
# Both should exist. If not, you're in the wrong directory!
Step 3: Pull Updates
git pull origin main
Step 4: Apply Updates
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py collectstatic --noinput
sudo systemctl restart clientst0r-gunicorn.service
Important Notes:
  • Find your path first! The application path varies by installation. Use the find command in Step 1 to locate YOUR installation.
  • Always verify with ls manage.py venv/ that you're in the correct directory before proceeding
  • Run commands ONE AT A TIME - don't paste them all at once
  • Check for uncommitted changes: git status before pulling updates
  • If you get "externally-managed-environment" error, make sure you activated the venv first
