Manual Update from CLI
Recommended: the same verified upgrade, from the command line

upgrade_apply runs exactly what Apply runs: it shows the revision, pins it by commit, verifies a release's signature, runs the preflight checks, takes a verified backup and then upgrades.

cd /path/to/your/clientst0r
venv/bin/python manage.py upgrade_apply
# or name the reviewed revision exactly:
venv/bin/python manage.py upgrade_apply --ref {{ update_info.target.ref|default:"vX.Y.Z" }} --sha {{ update_info.target.sha|default:"FULL_COMMIT_SHA" }}

Interrupted or failed? manage.py upgrade_status says what happened and how to resume or restore (docs/UPGRADE_AND_RECOVERY.md).

Show Manual Step-by-Step Instructions

For advanced users who prefer manual updates via command line:

Important: Copy and run these commands ONE AT A TIME, not all at once. Wait for each command to complete before running the next one.
Step 1: Navigate to Application Directory

Find where your application is installed:

find /home -name "manage.py" -type f 2>/dev/null | grep clientst0r
# This will show the path to your installation

Then navigate to that directory (replace with YOUR path from above):

cd /path/to/your/clientst0r
# Example: cd /home/administrator/clientst0r
# OR: cd /home/administrator
Step 2: Verify Location
ls manage.py venv/
# Both should exist. If not, you're in the wrong directory!
Step 3: Take a verified backup (database, uploads, keys)
venv/bin/python manage.py upgrade_backup
# must end with "Backup verified" -- do not migrate without it
Step 3b: Check out the release
git fetch origin tag {{ channels.stable.tag|default:"vX.Y.Z" }}
git -c gpg.format=ssh -c gpg.ssh.allowedSignersFile=deploy/root-helper/allowed_signers verify-tag {{ channels.stable.tag|default:"vX.Y.Z" }}
git reset --hard {{ channels.stable.tag|default:"vX.Y.Z" }}
Step 4: Apply Updates
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py collectstatic --noinput
sudo systemctl restart clientst0r-gunicorn.service
Important Notes:
  • Find your path first! The application path varies by installation. Use the find command in Step 1 to locate YOUR installation.
  • Always verify with ls manage.py venv/ that you're in the correct directory before proceeding
  • Run commands ONE AT A TIME - don't paste them all at once
  • Check for uncommitted changes: git status before pulling updates
  • If you get "externally-managed-environment" error, make sure you activated the venv first
