{% load i18n %}{% comment %} Primary navigation sidebar. Built by core.navigation.primary_nav() — every section, entry and nested page here already passed the same gates the server applies, so nothing is drawn that would answer 403. Layout: the filter and the collapse control at the top, the nine work sections in a scrolling list, Administration pinned at the foot (one link to the settings center), then the keyboard-shortcuts button. Behaviour lives in static/js/app_nav.js: * a section's header is a button: it expands / collapses the section and never navigates. Only the current section starts expanded; * the filter narrows the list as you type (labels + keywords), including the pages that are not sidebar links (Configure pages, settings pages, tabs) from pnav.extra; Enter opens the first match, or runs a global search when nothing matches; * the collapse button shrinks the sidebar to an icon rail (remembered; the default from 768px to 1199px). In the rail a section's button opens its pages as a flyout menu: Enter / Space / click open it, arrow keys move, Escape closes it and returns focus to the button; * below 768px the sidebar is a drawer opened from the bar's menu button. {% endcomment %}
